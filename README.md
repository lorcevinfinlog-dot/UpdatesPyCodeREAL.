# PyCodeEditor Update Server

Этот репозиторий создан для распространения автоматических обновлений программы **PyCodeEditor**.

## Для пользователей
Вам не нужно скачивать файлы отсюда вручную. Программа **PyCodeEditor** сама проверяет наличие новых версий в этом репозитории и устанавливает их в автоматическом режиме (через меню "Проверить обновления" или при запуске).

## Для разработчика
Здесь хранятся сгенерированные файлы обновлений:
- `update.json` — манифест с информацией о новой версии.
- `PyCodeEditor-*.zip` — архивы с файлами обновления.

**Важно:** Не удаляйте и не переименовывайте файлы в релизах, иначе автообновление у пользователей сломается!
