# PyCode Editor

**Легкий, молниеносный и невероятно мощный редактор кода с встроенным ИИ.**

PyCode Editor — это альтернатива тяжеловесным IDE (таким как VS Code), написанная с нуля с упором на производительность. Мы отказались от Electron и тяжелых фреймворков в пользу чистого JavaScript и Python.

## Главные фичи

- **Собственная виртуализация DOM:** Открывает файлы на миллионы строк без единого лага. Движок рендерит только то, что вы видите на экране.
- **Встроенные ИИ-Агенты:** Поддержка Claude, ChatGPT, Gemini, DeepSeek, Grok и локальных моделей (Ollama) прямо из коробки.
- **28+ тем и кастомизация:** Встроенный редактор тем. Меняйте цвета фона, панелей и текста в пару кликов. 
- **Поддержка языков:** 50 встроенных языков программирования, а также поддержка всех популярных языков.
- **Ультралегкий вес:** Программа весит всего ~15 МБ (против сотен мегабайт у конкурентов).

## Технологический стек

Редактор собран на мощном, но легком стеке:
- **Python** — ядро, работа с файловой системой, интеграция с ИИ.
- **HTML / CSS** — интерфейс и темы.
- **JavaScript (Vanilla)** — движок редактора (подсветка, скролл, вкладки) без сторонних библиотек.
- **Lua** — написание пользовательских скриптов.
- **ISS (Inno Setup)** — создание установщика.

## Установка

1. Скачайте последнюю версию установщика `PyCodeEditor-Setup.exe` из раздела **[Releases](../../releases)**.
2. Или посетите наш официальный **[сайт](https://statuesque-palmier-91d0c7.netlify.app/)** для скачивания.
3. Запустите установщик (Windows может показать предупреждение SmartScreen — нажмите «Подробнее» -> «Выполнить в любом случае»).
4. Настройки и ключи хранятся в папке `data`.
